# CraftPresence Toggle Addon

This mod adds a simple on/off button for [CraftPresence](https://modrinth.com/mod/craftpresence)'s Discord status in Mod Menu.

CraftPresence's `/cp shutdown` only lasts until the game restarts. So here's why this addon exists.

## Requirements
- Minecraft 1.21.1 Fabric
- CraftPresence (2.7.0 or newer)
- Mod Menu (optional)
